# Preflop ranges

JSON range files (one per format / players / position / stack depth / situation).
The schema and the editor/importer arrive in phase 3.

External ranges (Pokalab, preflopranges.app, purchased packs) are for **personal use**:
they are loaded by hand through the UI and are **not** shipped in packaged builds.
Only the empty format and system-computed ranges (`source: computed`) are distributed.
